An open-source speech-to-text app is not necessarily a meeting recorder. To replace an Otter or Fireflies workflow, check whether it captures both your microphone and the other participants, keeps a transcript, and produces the notes you need afterward.

**Anarlog and Meetily support microphone plus system-audio meeting capture. Amical is a dictation app; its current documentation still marks meeting transcription as coming soon.** This comparison covers those three projects without treating planned features as available.

If you need a browser server or a custom processing pipeline, start with our [self-hosted AI notetaker guide](/blog/selfhosted-ai-notetakers/). For other file and meeting workflows, browse the [transcription guides](/guides/transcription/).

## 1. Anarlog: meeting notes with control over the AI stack

[Anarlog](/) pairs a note editor with meeting recording, transcription, summaries, and chat. You can write your own memo during a call and use it alongside the transcript when generating a summary. Canonical sessions, notes, transcripts, and metadata live in local SQLite; attachments are separate local files, and Markdown is an export format.

![Anarlog](https://static.anarlog.so/blog/library/products/anarlog/desktop/2026-08-27-new-note.png)

**What it does:** capture microphone and computer audio, import recordings, search meetings, apply summary templates, and let you choose the speech and text AI independently. System-audio capture works across conferencing apps without adding a participant bot.

### Check the model requirements first

The current [model documentation](https://docs.anarlog.so/models-and-providers) distinguishes live transcription from processing after a recording:

- **Soniqo Parakeet Streaming** runs during a meeting; **Parakeet Batch** processes the recording afterward. Both require Apple Silicon. Batch is the recommended built-in option for hour-long calls and adds speaker labels for its supported languages.
- **Apple Speech** requires a supported Apple Silicon Mac, macOS 26, and compatible system language assets.
- **On-device file** accepts a whisper.cpp `.bin` model for transcription after recording on Apple Silicon. It is not the same as a live Whisper stream.
- **Windows, Linux, and Intel Macs** can use a Deepgram-compatible server on the computer or local network, a hosted provider with your own key, or Anarlog Cloud. Built-in on-device speech models are not available on those systems.

Summaries have a separate **Intelligence** selection. Choose Ollama, LM Studio, Unsloth, or eligible Apple Intelligence if the text processing must stay local too. Selecting local transcription alone does not make every enabled feature offline. Prepare models before disconnecting and follow the [offline Mac setup guide](/blog/offline-meeting-transcription-mac/).

### Free, Pro, and Enterprise boundaries

The community app is MIT-licensed. The [Free plan](/pricing/) includes local transcription and bring-your-own-key workflows; those API calls can still incur provider charges. Pro costs $14/month or $140/year and adds managed AI, encrypted CloudSync, sharing, and calendar integrations.

Hosted AI receives the input it needs. Optional sharing has a different data path from encrypted CloudSync, so review the [security information](/security/) when selecting a configuration.

A desktop download also does not establish a team-hosted capture service. Anarlog's customer-hosted capture and data-plane work is available through [early-partner Enterprise evaluations](/enterprise/) under separate commercial terms.

**Choose Anarlog if** you want manual notes, meeting transcripts, and summaries in one workspace with an explicit choice of AI provider. Check the speech path on your hardware before committing to an offline workflow.

## 2. Meetily: local meeting capture, with edition-specific extras

[Meetily Community](https://github.com/Zackriya-Solutions/meetily) captures mic and system audio, transcribes with Whisper or Parakeet, and supports audio import. It can generate summaries with Ollama or a configured cloud provider. Cloud summaries send text to that provider; a local speech model does not make that text request local.

![Meetily](https://static.anarlog.so/blog/articles/open-source-meeting-transcription-software/meetily.webp)

Windows and macOS have installers; Linux Community is a source build. You do not need development tools just to use an installer. Hardware acceleration depends on the build: macOS packages enable Metal/CoreML, while the packaged Windows Whisper build uses Vulkan. CUDA requires an appropriately configured NVIDIA source build.

### Community versus Pro

The current [Pro comparison](https://meetily.ai/pro/) separates the free MIT Community edition from commercial Pro:

- Community includes local transcription, local or BYOK summaries, and audio import.
- Pro adds speaker identification, custom summary templates, PDF/DOCX/Markdown exports, and MCP, webhook, and CLI integrations.
- Pro costs $10 per user per month billed annually, compared with the $25 regular monthly price. Enterprise uses custom commercial terms.

Pro's current product page lists speaker identification as available, even though an older section of the Community README still describes it as planned. Check the edition you install rather than assuming every feature is part of the MIT release.

**Choose Meetily if** local capture and summaries are the main workflow. Check whether speaker labels or advanced exports require Pro before treating Community as a complete replacement for your existing service.

## 3. Amical: useful dictation, meeting capture still planned

[Amical](https://amical.ai/docs) converts speech into text in the focused app. It is useful for drafting an email or dictating a follow-up after a call. Its MIT desktop project supports macOS and Windows; the README says Linux is unsupported because a native helper is missing.

![Amical floating recorder dictating a structured follow-up email in Gmail](https://static.anarlog.so/blog/library/products/amical/dictation/2026-08-30-demo.gif)

*The official [README demo](https://github.com/amicalhq/amical#-overview) shows a dictated Gmail draft.*

The [desktop quick start](https://amical.ai/docs/quick-start) documents push-to-talk, hands-free dictation, and microphone/accessibility permissions. It marks Meeting Transcriptions and Voice Commands as coming soon. The README likewise lists mic-plus-system meeting transcription as planned. Do not choose it on the assumption that it records both sides of a call today.

Amical's [local-model guide](https://amical.ai/docs/local-ai-models) separates Whisper speech models from language processing through Ollama or a local OpenAI-compatible endpoint. Download models and select the local path before relying on offline dictation.

### Local use versus cloud plans

The current [pricing page](https://amical.ai/pricing) includes unlimited local dictation on Free plus 2,000 cloud words per week. Premium offers unlimited cloud dictation at $10/month or $7/month billed as $84/year. Enterprise is custom.

**Choose Amical if** dictation into other applications is your need. For meeting capture, evaluate Anarlog or Meetily instead and revisit Amical when its documented feature status changes.

## How to test an open-source alternative before switching

Use a short call representative of your real work:

1. Wear your usual headset and confirm the recording includes your voice and the remote participant. A microphone-only dictation test does not establish system-audio capture.
2. Select speech and summary providers separately. After downloading local models, disconnect if offline operation is a requirement and check both stages.
3. Try the languages, overlapping speech, and terminology you actually encounter. Review the transcript and speaker labels before relying on the results.
4. Export a transcript and summary, then confirm the format and edition meet your workflow. Inspect the relevant code license separately from commercial services.

For a meeting editor with portable exports, [download Anarlog](/download/) and check the [source](https://github.com/fastrepl/anarlog). For broader free options, compare [free transcription software](/blog/free-transcription-software/).

## Frequently asked questions

### Are all open-source transcription apps free?

The three community projects above use MIT licenses, but services and editions differ. Local use can avoid API charges, while cloud processing, managed plans, and commercial upgrades can cost money. Check the exact edition and model path.

### Can these tools replace a meeting bot?

Anarlog and Meetily capture computer audio and your microphone on your device. Amical's documented workflow is dictation; meeting capture is still planned. For a shared server rather than a desktop recorder, compare the separate [self-hosted deployment options](/blog/selfhosted-ai-notetakers/).

### Does open source guarantee that meeting data stays local?

No. You can inspect the code, but your configuration determines the processing path. Review speech, summaries, sharing, sync, and integrations separately. A cloud summary can receive transcript text even when speech recognition runs locally.

### How much hardware do I need?

There is no single RAM requirement for all three apps and every model. Check the model size, platform support, and acceleration path, then test a representative recording. Anarlog's built-in speech options require supported Apple Silicon hardware; its local-server route is a separate setup.
